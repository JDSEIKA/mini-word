Versión: 0.0.10 Beta

|---|---|
| `Ctrl+N` | Nuevo |
| `Ctrl+O` | Abrir |

| `Ctrl+Shift+S` / `F12` | Guardar como |

| `Ctrl+Z` | Deshacer |

| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Cortar, copiar, pegar |
| `Ctrl+Shift+V` | Pegar sin formato |
| `Ctrl+Alt+V` | Pegado especial |
| `Ctrl+A` | Seleccionar todo |
| `Ctrl+F` | Buscar |

| `F7` | Ortografía |

| `Ctrl+Enter` | Salto de página |

## Formato de carácter

| Atajo | Acción |
|---|---|
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Negrita, cursiva, subrayado |
| `Ctrl+Shift+>` / `Ctrl+Shift+<` | Aumentar/disminuir tamaño |
| `Ctrl+]` / `Ctrl+[` | Aumentar/disminuir tamaño en 1 punto |
| `Ctrl+Shift+C` | Copiar formato; se aplica a la siguiente selección |
| `Ctrl+Shift+Space` | Espacio de no separación |

## Formato de párrafo

| Atajo | Acción |
|---|---|
| `Ctrl+E` / `Ctrl+L` / `Ctrl+R` / `Ctrl+J` | Centrar, izquierda, derecha, justificar |
| `Ctrl+M` / `Ctrl+Shift+M` | Aumentar/disminuir sangría |
| `Ctrl+1` / `Ctrl+5` / `Ctrl+2` | Interlineado sencillo, 1,5, doble |
| `Ctrl+Shift+L` | Viñetas |
| `Ctrl+Shift+7` | Numeración |
| `Ctrl+Shift+N` | Estilo Normal |
| `Ctrl+0` | Estilo Normal (compatibilidad Word) |
| `Ctrl+Alt+1/2/3` | Título 1/2/3 |

## Revisión y navegación

| Atajo | Acción |
|---|---|
| `Ctrl+Shift+E` | Control de cambios |
| `Ctrl+Alt+M` | Comentarios |
| `Ctrl+Shift+Up/Down` | Seleccionar hasta el inicio/fin del párrafo |
| `Alt+Shift+Up/Down` | Mover el párrafo |
| `F9` | Actualizar campos |
| `F11` / `Shift+F11` | Campo siguiente/anterior |
| `F5` / `Ctrl+G` | Ir a página |

## Zoom

| Atajo | Acción |
|---|---|
| `Ctrl++` / `Ctrl+-` | Acercar/alejar |
| `Ctrl+Alt+0` | Restablecer zoom al 100 % |
| `Ctrl+rueda` | Zoom con la rueda |

`Ctrl+0` ya no restablece el zoom: se reservó para el estilo Normal, como en Word.

## Limitaciones

- `Ctrl+Shift+C` copia el formato y lo aplica a la siguiente selección; no hay cursor de pincel persistente.
- `Ctrl+Alt+V` ofrece texto sin formato o con formato; no implementa todos los formatos de Word.
- En teclados donde `Ctrl+Alt` actúa como AltGr, algunos atajos de Título pueden depender del layout.
- La lista de atajos cubre las funciones existentes; no hay atajos para gráficos, SmartArt o ecuaciones porque esas funciones no existen.
